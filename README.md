# BudgetDarwin (`min-token`)

tokens& **Self-Evolving Agents Hackathon** — Jul 24, 2026 · SF

An autonomous agent that evolves how it routes work across models so you **keep quality high and stop wasting compute money**.

> Most agents send every problem to the largest model. BudgetDarwin only spends heavily where it matters.

**Goal:** quality ≥ 90% (Senso-grounded) while cutting $/batch ≥ 40% vs always-premium.
